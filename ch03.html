3.1 人话版：反向传播 / AdamW / 学习率

人话版 训练三件套总览
名称一句话
反向传播 Backpropagation算误差梯度，告诉模型每个权重该往哪个方向改
AdamW常用优化器：拿着梯度去更新权重
学习率 Learning Rate控制每次更新时步子迈多大

①反向传播（Backpropagation）

通俗理解

  • 正向传播：输入文字 → Embedding → Attention → MLP → logits → 交叉熵 loss（误差）
  • 反向传播：从 loss 往回倒推，一层一层算：每个权重对这个误差贡献有多大（梯度 gradient）

梯度 = 这个参数稍微变大一点，loss 会变大还是变小、变多少：

梯度为正

参数变大 → loss 变大 → 要减小参数（往反方向走）

梯度为负

参数变大 → loss 变小 → 要增大参数

  • 前向跑一遍，算出 loss
  • 链式法则：从最后一层往第一层，逐层求梯度
  • 把梯度交给优化器（AdamW）去更新权重

比喻：loss 是海拔；反向传播告诉你「往哪个方向下山」。

②AdamW（详解）

全称：Adam with decoupled Weight Decay —— 带解耦权重衰减的 Adam 优化器。 现在训练 GPT、Qwen、Gemma 这类 Transformer 大模型几乎都用它，是 LLM 训练的标配优化器。NanoGPT 同样用 torch.optim.AdamW。

工作：拿到反向传播算出的梯度，决定怎么更新每一份权重。

大白话比喻

Adam 本身像很聪明的下坡工具（自动给每个参数调步长）。但原版 Adam 做「权重衰减」时把两件事混在一起，效果打折；AdamW 把「往下走（梯度更新）」和「拉着权重别太大（权重衰减）」拆开单独做，互不干扰。

Adam（耦合）

把衰减惩罚加到梯度里一起算，再被 Adam 的自适应缩放扭曲 → 衰减强度不准

AdamW（解耦）

梯度更新、权重衰减分两步；衰减直接作用在权重上，少受自适应学习率干扰 → 抑制过拟合更靠谱

继承自 Adam 的两个核心能力

一阶动量（$\beta_1$，常用 0.9）
记录梯度趋势 ≈ 下坡时记住之前方向，减少抖动（对应状态 $m$）
二阶矩（$\beta_2$，常用 0.999）
记录梯度大小 ≈ 自动给不同参数配不同有效步长：梯度大的步子小、梯度小的步子相对大（对应状态 $v$）

和普通 Adam 的关键差别（示意公式）

下面把「自适应后的有效梯度」仍写成「梯度」，只为看清衰减是否混进去；真实 Adam/AdamW 还会用 $m/\sqrt{v}$ 等，并有偏差修正。

耦合 vs 解耦（示意） Adam  ：weight = weight − lr × (梯度 + 衰减项)
AdamW：weight = weight − lr × 梯度 − lr × 衰减系数 × weight
→ 衰减不再混进梯度里，是独立的一步，也就是「解耦」
$$\underbrace{\theta \leftarrow \theta - \eta\,\hat{m}/\sqrt{\hat{v}}}_{\text{Adam 式自适应梯度步}} \quad\text{再}\quad \underbrace{\theta \leftarrow \theta - \eta\,\lambda\,\theta}_{\text{AdamW 解耦权重衰减}}$$

$\lambda$ = weight_decay。衰减项与自适应缩放分开，这就是 decoupled 的含义。

权重衰减（weight decay）是干嘛的？

  • 惩罚权重数值不要变得太大，减轻「死记」训练数据（过拟合），让泛化更好
  • 注意：不是去减小 loss 本身，而是约束模型（正则），和交叉熵目标是两件事

一句话：AdamW = Adam 的聪明步长 + 解耦的 weight decay；大模型训练标配。

③学习率（Learning Rate，lr）

学习率 = 更新权重时的步长。先用最简单的梯度下降来建立直觉：

$$\text{新权重} = \text{旧权重} - \text{学习率} \times \text{梯度}$$

（AdamW 实际还会用 $m$、$v$ 变形成更稳的更新，但「lr 控制步子大小」这个直觉不变。）

lr 太大

步子太大，来回震荡；loss 不降甚至飞涨、不收敛

lr 太小

步子太小，训练极慢，很久才收敛

  • 直观：lr=0.1 容易横跳；lr=1e-4 慢慢挪，稳但慢
  • 你的 NanoGPT 小模型配置默认 learning_rate=1e-3（小网络可以稍大）
  • Qwen / Gemma 类大模型预训练常见约 1e-4 ~ 3e-4；微调通常更小
  • 大模型还会配：warmup 预热（前期慢慢升 lr）+ cosine 余弦衰减（后期慢慢降，精细微调）

④三者串起来（NanoGPT 就是这个环）

完整训练一步 ① 输入一批 token → 前向 → 算出 CE loss
② 反向传播 → 求所有权重的梯度
③ AdamW 接收梯度（动量 + 权重衰减）
④ 用学习率控制步长，更新权重
⑤ 循环，直到 loss 足够低 / 达到 max_iters

⑤高频配套术语

术语含义
Weight Decay权重衰减：惩罚过大权重、约束模型（不是直接减小 CE loss）；AdamW 将其与梯度更新解耦
Warmup预热：训练前期学习率慢慢涨上去
Cosine LR decay余弦衰减：学习率随步数平滑下降
Gradient Clip梯度裁剪：限制梯度范数，防止爆炸

3.2 前向有了，还缺「怎么改参数」

第 1–2 课讲的是：输入 → 算出 logits → Softmax → CrossEntropy → 得到一个标量 loss。

训练要做的下一件事：让 loss 变小。手段是改模型参数 $\theta$（Embedding、Attention、MLP、lm_head 里所有权重）。

$$\theta \leftarrow \theta - \eta \cdot \nabla_\theta \mathcal{L}$$
$\nabla_\theta \mathcal{L}$（梯度）
loss 对每个参数的偏导：告诉你「这个参数变大一点，loss 会升还是降、升多少」
$\eta$（学习率 learning rate）
每次更新走多大步。你配置里默认 1e-3

梯度指出方向；学习率决定步长；两者合起来 = 一次参数更新。

通俗版：公式在说什么

前面算完 loss，只知道「猜得差」；还不知道该拧哪颗螺丝、往哪拧。这一节就是在说：用公式改参数，让下次猜得好一点。

把公式拆成三样东西：

θ ← θ − η · ∇L 新参数 = 旧参数 − 学习率 × 梯度
符号人话
$\theta$（theta）模型里那一大堆可调数字（权重）。NanoGPT 里几万～上百万个
$\mathcal{L}$（loss）这次猜错得有多狠（一个数，越小越好）
$\nabla_\theta \mathcal{L}$（梯度）对每一个参数：稍微调大一点，loss 会升还是降、升多少。像「下山指南针」
$\eta$（eta，学习率）步子迈多大。你配置里常是 1e-3 = 0.001
前面的减号 $-$故意逆着梯度走——梯度指向「loss 变大」的方向，减去它才是下山

爬山比喻（最重要）：

  • loss = 海拔高度，目标是走到谷底
  • 梯度 = 坡朝哪边变陡（哪边海拔升得快）
  • 更新 = 朝反方向迈一小步（所以公式里是减号）
  • 学习率 = 这一步迈多远：太大容易跨过山谷来回晃，太小挪得太慢

一个数的玩具例子：

假设只有一个参数 旧权重 θ = 2.0
算出来梯度 = +0.5（意思：θ 再变大，loss 会变大）
学习率 η = 0.1
新权重 = 2.0 − 0.1 × 0.5 = 1.95
→ 把 θ 略调小，符合「梯度为正就减小参数」

和后面两节的关系：

  • 梯度从哪来？→ 下一节反向传播自动算
  • 真训练时很少用「裸」公式，而用 AdamW 更稳地走每一步；但「减梯度、乘学习率」这个直觉不变

先记住：看到 loss → 算出每个权重该往哪拧（梯度）→ 乘上步长拧一下 → 反复，直到 loss 变小。

3.3 反向传播在干什么

神经网络是很多可微运算的复合函数。反向传播用链式法则，从 loss 往回传，自动给每个参数算出梯度。

1
前向保存中间激活；算出 loss
2
loss.backward()从 CE → Softmax/logits → lm_head → Block×N → Embedding，逐层回传
3
每个参数拿到 .grad形状与参数相同，表示「该怎么改」

对应 train.py：

logits, loss = model(X, Y)   # 前向
loss.backward()              # 反向：填充各参数 .grad
# 然后 optimizer.step() 用梯度更新权重
你需要记住的直觉

不必手算每一层的偏导。PyTorch 的 autograd 替你做链式法则。你要理解的是：loss 变小 ↔ 参数沿「降低 loss 的方向」移动。

第 2 节通俗版：反向传播在干嘛

前向像考试交卷打分：算完得到一个总分 loss。
反向像阅卷回放：从总分倒推——哪支笔（哪个权重）害你丢分最多。

  • loss.backward() = 自动给每个权重贴一张纸条 .grad：「往这边拧会更好 / 更差」
  • 你不用手算公式；框架从最后一层往第一层用链式法则推回去
  • 推完还没改权重——只是写好「说明书」；真正拧螺丝是下一步优化器
两行代码的人话 model(X,Y) → 先考试打分得到 loss
loss.backward() → 再回放：每个旋钮该怎么拧写在 .grad 上

3.4 为什么用 AdamW

朴素 SGD：每步 $\theta \leftarrow \theta - \eta \cdot g$。简单，但学习率难调、收敛可能抖。

更完整的 AdamW 说明见上方 人话版 · ② AdamW 详解（解耦衰减、$\beta_1/\beta_2$、与 Adam 公式对比）。

nanoGPT 里在 model.configure_optimizers 创建 AdamW（并对 2D 权重做 weight decay、偏置/LayerNorm 通常不衰减）；train.py 里：

scaler.step(optimizer)   # 实质调用 AdamW 更新
optimizer.zero_grad(set_to_none=True)  # 清空梯度，准备下一步
和你模型规模的关系

轻量配置约 0.80M 参数。每一步 AdamW 都要为这些参数维护梯度（以及一阶/二阶动量状态）。参数越多，显存与计算越大——这就是为什么先用小模型练手。

第 3 节通俗版：AdamW 跟「裸减梯度」差在哪

最笨的下山：每步 新参数 = 旧参数 − 学习率 × 当前梯度（SGD）。路滑、噪声大时容易左晃右晃。

AdamW 更像带惯性的智能登山杖：

  • 记得最近几步往哪走（动量）→ 少被单步噪声带跑
  • 哪个旋钮梯度一直很大，就自动迈小点；一直很小，就允许迈大点
  • 另外单独「拉着权重别胀太大」（weight decay）→ 减轻死记硬背

optimizer.step() = 按 AdamW 规则真正改权重；zero_grad() = 把上一步的纸条撕掉，避免和下一步粘在一起。

3.5 学习率调度：warmup + cosine

不是全程用固定 learning_rate=1e-3。get_lr(it) 会随 step 变化：

A
Warmup（前 warmup_iters 步）学习率从接近 0 线性升到峰值，避免一开始步子太大把随机初始化冲垮
B
Cosine 衰减按余弦曲线从峰值降到 min_lr，后期细调
C
超过 lr_decay_iters保持 min_lr
$$\eta(t)=\begin{cases} \eta_{\max}\cdot\frac{t+1}{T_{\mathrm{warm}}+1} & t < T_{\mathrm{warm}}\\[6pt] \eta_{\min}+\frac{1}{2}(1+\cos\pi\frac{t-T_{\mathrm{warm}}}{T_{\mathrm{decay}}-T_{\mathrm{warm}}})(\eta_{\max}-\eta_{\min}) & \text{否则} \end{cases}$$

莎士比亚配置里常见：warmup_iters=100，lr_decay_iters 与 max_iters 对齐。

第 4 节通俗版：为什么学习率还要「先升后降」

学习率 = 每一步迈多远。刚开始参数几乎是乱的——一上来就大步跑容易摔。

  • Warmup（热身）：前几十/上百步，步子从很小慢慢加大到峰值（如 1e-3）
  • Cosine 衰减：后面按平滑曲线把步子再慢慢缩小，方便在谷底附近精细挪
开车类比 轻点油门起步（warmup）→ 上高速（峰值 lr）→ 靠近目的地减速（cosine）→ 停车微调（min_lr）

上面的公式不用背，只要知道：步长随训练进度在变，不是死盯一个 η。

3.6 梯度裁剪（grad clip）

torch.nn.utils.clip_grad_norm_(model.parameters(), grad_clip)

若某步梯度爆炸（范数过大），把它缩放到不超过阈值。训练更稳，尤其是深层网络。

第 5 节通俗版：梯度裁剪

偶尔某一步算出的「拧法」特别猛（梯度范数爆表），按原计划拧可能把模型拧飞、loss 突然飙高。

梯度裁剪 = 设一个上限：方向照旧，力气太大就按比例减弱——像限速，防止一次踩死油门。

3.7 和 loss 曲线的关系

你看到的现象背后在发生什么
loss 稳步下降梯度方向大致有用，步长合适，参数在改善似然
loss 剧烈震荡学习率可能偏大，或 batch 噪声大
loss 几乎不动学习率过小，或模型/数据不匹配
train↓ val↑可能过拟合（第5章）——优化仍在降训练 loss，但泛化变差
第 6 节通俗版：曲线是「下山日记」

图上的 loss，就是每走一段记下的海拔。第 2–5 节那些工具，最终都反映在曲线好不好看上：

  • 稳稳往下：指南针（梯度）靠谱，步子（lr）合适，AdamW 在好好干活
  • 上下乱跳：步子可能太大，或这一批数据太「吵」
  • 几乎横着：步子太小，半天走不出多远
  • 练习海拔↓、考试海拔↑：过拟合——背熟了训练集（见 第5章）
串起来 一个 training step，用大白话走一遍
  1. 拿一小撮莎士比亚字符（一个 batch）
  2. 前向：猜下一个字 → 打出 loss（这回错多少）
  3. 反向：backward() 给每个权重写上「该怎么拧」
  4. （可选）裁剪：拧法太猛就限速
  5. AdamW + 当前学习率：真正改参数
  6. zero_grad：清空旧梯度，准备下一撮数据

把上面循环几百～几千次，你就看到 loss 从约 4.19 降下来；曲线就是这份「下山日记」。

3.8 扩展：预训练里同一套旋钮如何被放大

在大规模预训练报告里，你仍会反复看到：

  • AdamW（或变体）+ weight decay
  • warmup + cosine / 多段衰减
  • grad clip 与混合精度带来的数值稳定问题

NanoGPT 是缩小版沙盘：参数少、步数少，但决策逻辑一致。调 lr 导致震荡、warmup 过短不稳——这些直觉可以直接迁移。

自测题

Q1：loss.backward() 和 optimizer.step() 谁先谁后？各做什么？

参考：先 backward 算梯度，再 step 用梯度改参数。

Q2：为什么训练初期常要 warmup，而不是一上来就用最大学习率？

参考：初期网络随机，大步长容易破坏表示；先小步再加大更稳。
