4.1 总览：while True 里发生了什么

0
启动一次读配置 → 建模型 → AdamW → 搬到 device（mps）
1
设学习率get_lr(iter_num) → 写入 optimizer
2
定期评估每 eval_interval 步：train/val loss → 记曲线 → 可能存 ckpt
3
训练一步forward → backward → clip → AdamW step → zero_grad
4
打日志 / 计数打印 iter loss；iter_num += 1；超过 max_iters 则 break
5
结束后画图matplotlib 保存 loss_curve.png

4.2 步骤详解（人话版）

把上面那张循环图里的「橙色训练一步」拆开：先造题 → 做题打分 → 对照答案改卷 → 偶尔摸底考试 → 存档。

A. get_batch：造训练样本

人话

从莎士比亚长文里随机剪一小段当题目。

  • X = 题目：给模型看的字符（例如 To be or not to b）
  • Y = 标准答案：每个位置「下一个该是什么字」（整体比 X 右移 1 格）
  • 一次不只剪 1 段，而是一次拿 batch_size 段一起练（如 64 段），每段长 block_size（如 256 字）
x = data[i : i+block_size]
y = data[i+1 : i+1+block_size]   # 右移 1 位 = 下一字符
迷你例子（字符级） 原文片段：H e l l o
X（题）：H e l l
Y（答）：e l l o　← 每个位置的「下一个字」

形状约 (64, 256)。细节见 第1章。

B. 前向：model(X, Y)

人话

做题 + 当场打分。模型看 X，猜每个位置的下一个字，再跟 Y 比，算出一个总分 loss。

  • 猜得越准 → loss 越小；瞎猜 → loss 大
  • 内部流水线：Embedding → 好几层 Block → lm_head（第2章）
  • 终端里 iter … loss … 打印的，基本就是这一步的分数
logits, loss = model(X, Y)
  • logits：每个位置对「词表里每个字」打的原始分（还没变成概率）
  • loss：平均 CrossEntropy——「猜错有多惨」的一个数（第1章）
  • 若开了梯度累积，代码里会先除一下再乘回来，你当「同一份分数的记账技巧」即可

C. 反向与更新（第3章）

人话 · 一行一句

分数出来了还没改模型。下面这几行才是对照错题改参数：

  1. …backward() → 回放错题：每个旋钮该怎么拧，写在 .grad 上
  2. clip_grad_norm_ → 拧法太猛就限速，防止一步拧飞
  3. scaler.step(optimizer) → AdamW 真正改权重（你 Mac 上 MPS/FP32 时，scaler 几乎等于直接 step）
  4. scaler.update() → 混合精度记账用的；FP32 时可当「顺手维护一下」
  5. optimizer.zero_grad(…) → 撕掉旧纸条，下一圈重新写，别和下一题粘在一起
scaler.scale(loss).backward()
# clip_grad_norm_ ...
scaler.step(optimizer)
scaler.update()
optimizer.zero_grad(set_to_none=True)

更完整的下山比喻见 第3章通俗版。

D. estimate_loss：评估时发生什么

人话

训练是「刷题改卷」；评估是摸底考试：不动旋钮，只量现在水平。

  • 从训练集、验证集各抽好多小段，算平均 loss
  • @torch.no_grad()：不建「怎么拧」的计算图——考试不改卷，省内存也更快
  • model.eval()：关掉训练时的随机扰动（如 Dropout），分数更稳
  • 考完 model.train() 切回刷题模式；你改过的代码会把分数记进列表，最后画成曲线
@torch.no_grad()
def estimate_loss():
    model.eval()
    # 对 train / val 各抽 eval_iters 个 batch，平均 loss
    model.train()
    return out

E. 存 checkpoint

人话

摸底考得好（val loss 创新低）就存档：把当前模型拍成快照 ckpt.pt。

  • 里面有：模型权重、优化器状态、训练到第几步、最好的 val loss、配置
  • 以后 sample.py 生成莎士比亚腔，读的就是这份存档（第5章）
  • 中途挂了也能 resume 接着练，不用从零开始

通常要求 iter_num > 0 才存，避免第 0 步还没练就覆盖掉好存档。

4.3 终端两行日志分别是什么

打印频率含义
step N: train loss …, val loss … 每 eval_interval（如 250） 多 batch 平均后的评估指标；用来画曲线、存盘
iter N: loss …, time …ms 每 log_interval（如 10） 当前这一步的训练 loss（单次 batch，噪声更大）

4.4 完整训练命令在循环中的效果

python train.py config/train_shakespeare_char.py \
  --device=mps --compile=False \
  --n_layer=4 --n_head=4 --n_embd=128 --max_iters=1500
  • 设备：每步张量在 MPS 上算
  • 模型：4 层小 GPT，约 0.8M 参数
  • 循环：iter_num 从 0 加到 1500 后 break
  • 评估：0, 250, 500, …, 1500 共多个点写入曲线

4.5 扩展：自己给 train.py 做「阅读标注」

建议在编辑器里给 train.py 加五类书签（不必改逻辑，只为导航）：

  1. 配置与模型构建
  2. get_batch
  3. 前向 model(X, Y) 与 loss
  4. backward / clip / step
  5. estimate_loss 与 checkpoint

能不看笔记、只靠书签把一圈训练讲下来，第 4 章才算过关。

自测题

Q1：为什么评估要用 torch.no_grad()，而训练 step 不能？

参考：评估只需 loss 数值；训练需要梯度来更新参数。

Q2：iter loss 和 step train/val loss 哪个更适合判断「是否过拟合」？为什么？

参考：看 step 的 train vs val；单步 iter loss 噪声大且没有 val。
